================================================================================
                         QUICK START GUIDE
================================================================================

STEP 1: Choose Environment
  copy .env.test .env      (for TEST environment - recommended)
  copy .env.uat .env       (for UAT environment)
  copy .env.prod .env      (for PROD environment)

STEP 2: Add Credentials
  Edit .env and add:
    BEARER_TOKEN=your_token_here
    AUTH_TOKEN=your_auth_token_here

STEP 3: Run Tests
  npm run test:test                     (run all TEST tests)
  npm run test:test:tags "@smoke"       (run TEST smoke tests)
  npm run test:test:tags "@opsera"      (run Opsera tests)

STEP 4: View Reports
  npm run report
  Open: reports/html/index.html
